# Hotspot Network Visualization

مشروع ويب تجريبي لعرض تصور بصري تفاعلي للشبكات ونقاط الاتصال.

## الملف الرئيسي
- `deepseekNetwork.html` — صفحة HTML الرئيسية للمشروع.

## التشغيل

افتح الملف مباشرة في متصفح حديث.

على Windows:
```powershell
start deepseekNetwork.html
```

أو شغّل خادماً محلياً:
```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/deepseekNetwork.html`.

## التقنيات
- HTML
- CSS
- JavaScript
- Canvas API (عند استخدامه في الصفحة)
